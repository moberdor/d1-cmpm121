# D1 starter

A minimal TypeScript/Vite browser project with Deno checks and GitHub Pages deployment.

Click the bee to earn honey
Use honey to buy bees which increase honey per click
As you collect more honey, more bees become available
Some bees or non-bees give you honey / bees at a fixed rate
https://moberdor.github.io/d1-cmpm121/

To build / run in VS code:
Deno will need to be installed, as well as the Deno plug in inside VS code
Open a terminal and enter "deno run -A npm:vite@8.3.1 build"
Then enter "deno run -A npm:vite@8.3.1 preview"

To add new Bees, edit Upgrade array in main.ts
